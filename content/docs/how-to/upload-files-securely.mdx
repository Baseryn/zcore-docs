File uploads are high-risk entry points. ZCore's `LocalStorageProvider` defends your server against Path Traversal, Denial of Service (large files), and executable masquerading (e.g., PHP or `.exe` files disguised as `.jpg`).

<Steps>
  <Step>
    ### 1. Configure the Storage Provider

    Initialize `LocalStorageProvider` with your security validators and register it in the IoC container:

    ```python
    # main.py or storage_config.py
    from zcore.storage import (
        LocalStorageProvider,
        SafeMimeTypeValidator,
        MaxFileSizeValidator,
        FileExtensionValidator,
        StorageProvider
    )
    from zcore.kernel.di import container

    storage = LocalStorageProvider(
        base_path="./storage/uploads",
        validators=[
            # 1. Enforce strict 5 MB file size limit
            MaxFileSizeValidator(max_size_mb=5),
            
            # 2. Check file extension
            FileExtensionValidator(allowed_extensions=[".png", ".jpg", ".jpeg", ".webp", ".pdf"]),
            
            # 3. Inspect binary Magic Bytes to detect disguised scripts
            SafeMimeTypeValidator(allowed_mimes=["image/png", "image/jpeg", "image/webp", "application/pdf"])
        ]
    )

    # Register as the active storage provider singleton
    container.register_singleton(StorageProvider, storage)
    ```
  </Step>

  <Step>
    ### 2. Create the Upload Endpoint

    Inject `StorageProvider` into your FastAPI route and upload the `UploadFile` payload:

    ```python
    # routers.py
    from fastapi import APIRouter, UploadFile, File
    from zcore import Inject
    from zcore.storage import StorageProvider

    router = APIRouter(prefix="/media", tags=["Media"])

    @router.post("/avatar")
    async def upload_avatar(
        file: UploadFile = File(...),
        storage: Inject[StorageProvider]
    ):
        # Saves to ./storage/uploads/avatars/ with collision-resistant UUID filename
        saved_path = await storage.upload(file, related_type="avatars")
        return {"file_path": saved_path}
    ```
  </Step>

  <Step>
    ### 3. Secure File Deletion

    Delete stored assets safely. ZCore verifies that the path resides strictly inside the `base_path` before deleting:

    ```python
    @router.delete("/avatar")
    async def delete_avatar(file_path: str, storage: Inject[StorageProvider]):
        success = await storage.delete(file_path)
        return {"deleted": success}
    ```
  </Step>
</Steps>

<Callout type="info" emoji="🛡️">
  **Triple-Layer Security Architecture:**
  * **Magic Bytes Verification:** Inspects the first 2048 header bytes against format signatures. Any binary containing PHP execution tags (`<?php`), HTML scripts (`<script`), Unix shebangs (`#!/`), or Windows PE headers (`MZ`) is immediately rejected with a critical security alert.
  * **Path Traversal Defense:** Both `upload()` and `delete()` resolve system paths strictly and assert `.is_relative_to(base)`. Any directory breakout attempt (e.g., `../../etc/passwd`) is blocked.
  * **Collision-Resistant Naming:** Uploaded files are automatically renamed with randomized UUID prefixes (`uuid4()[:15] + ext`) to prevent filesystem filename overwrites.
</Callout>
