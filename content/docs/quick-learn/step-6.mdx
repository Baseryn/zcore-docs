Writing the same `SELECT`, `INSERT`, and `UPDATE` queries for every model is tedious. ZCore's `BaseRepository` eliminates this boilerplate.

<Steps>
  <Step>
    ### Create the Repository

    Open `tasks/repositories.py`. Inherit from `BaseRepository` and pass your model type:

    ```python
    # tasks/repositories.py
    from sqlalchemy.ext.asyncio import AsyncSession
    from zcore import BaseRepository
    from .models import Task

    class TaskRepo(BaseRepository[Task]):
        def __init__(self, db: AsyncSession):
            super().__init__(model=Task, db=db)
    ```
  </Step>

  <Step>
    ### What You Just Unlocked

    <Callout type="info" emoji="📦">
      **Out-of-the-box features:** By writing this empty class, `TaskRepo` now has access to:
      * **CRUD & Mutations:** `create`, `create_multi`, `get`, `get_by_ids`, `exist`, `count`, `update`, and `delete` (with direct primary key or model instance support).
      * **Soft-Delete & Restoration:** Built-in `restore` and atomic batch `restore_multi` for recovering soft-deleted records, plus a `force=True` flag on `delete`/`delete_multi` for permanent hard-deletes.
      * **Batch Operations:** `update_multi`, `delete_multi` (with dialect-aware `RETURNING` optimizations).
      * **Pagination:** `get_list` (supports both Page-Number and high-performance Keyset Cursor pagination).
      * **Dynamic Search & Projection:** `search` with selective column loading (`fields` via `load_only`), custom SQLAlchemy options (`options`), depth-limit validation, inverted operators (`not_like`, `not_in`, `not_between`, `is_not_null`), and boolean `not` grouping.
      
      All methods are fully asynchronous and type-hinted.
    </Callout>
  </Step>

  <Step>
    ### No Lock-In

    If you have a complex query that requires a raw SQL `JOIN` or a CTE, you can simply write a new custom method or override any existing CRUD method inside `TaskRepo`. Because ZCore never hides the `AsyncSession` from you, you have full access to SQLAlchemy's power directly inside your repository.
  </Step>
</Steps>
