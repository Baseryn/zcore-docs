In this first step, we will set up the foundation of our project. ZCore is designed to be zero-config out of the box, with automated virtual environment initialization and cryptographically secure secret generation.

<Steps>
  <Step>
    ### Install the Framework

    Install ZCore with all its standard dependencies (FastAPI, SQLAlchemy, Pydantic, Questionary, Rich, etc.). The `[all]` extra ensures you get the complete toolkit.

    ```bash
    pip install fastapi-zcore-framework[all]
    ```
  </Step>

  <Step>
    ### Scaffold the Project with the CLI

    Use the `zc init` command to create a project structure. The CLI will interactively ask for your database preference (SQLite, PostgreSQL, or MySQL) and package manager (`uv` or `pip`).

    ```bash
    zc init task_manager && cd task_manager
    ```

    This command automatically:
    * Generates a pre-configured `.env` file with a freshly generated 64-character `SECRET_KEY`.
    * Creates `main.py`, `requirements.txt`, and `.gitignore`.
    * Initializes an isolated virtual environment (`.venv`) and installs project dependencies if selected.

    <Files>
      <Folder name="task_manager" defaultOpen>
        <File name="main.py" />
        <File name=".env" />
        <File name="requirements.txt" />
        <File name=".gitignore" />
        <File name="zcore_dev.db" />
      </Folder>
    </Files>
  </Step>

  <Step>
    ### Secret Keys & Environment Management

    `zc init` already populates `.env` with a cryptographically strong `SECRET_KEY`. However, if you need to generate a new key or rotate credentials later, run:

    ```bash
    zc gensecret
    ```

    To generate a clean `.env.example` schema from your Pydantic settings at any time:

    ```bash
    zc genenv -o .env.example -f
    ```
  </Step>

  <Step>
    ### Understand the Settings Class

    Open `main.py`. You will see that ZCore imports `settings` from `zcore.config`. This `settings` object is a `SettingsProxy` that reads from your `.env` file using Pydantic V2 Settings.

    ```python
    # main.py (excerpt)
    from zcore import settings

    # ZCore reads DATABASE_URL, SECRET_KEY, DEBUG, etc., automatically
    print(settings.PROJECT_NAME)
    print(settings.DATABASE_URL)
    ```

    <Callout type="info" emoji="💡">
      **Deep Dive:** The `settings` object is a Proxy. This means importing it at the top of your files is completely safe and doesn't trigger premature initialization of the Dependency Injection container. Values are resolved lazily when accessed.
    </Callout>
  </Step>
</Steps>

Excellent! Your environment is now secure and ready. In the next step, we will examine database initialization.
