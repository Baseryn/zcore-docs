The `Security` class is a unified coordinator for cryptographic and authentication operations. It provides memory-hard password hashing (Argon2id), JSON Web Token (JWT) encoding/decoding, secure hexadecimal generation, and SHA-256 digests.

## Class Definition

```python
from zcore import Security
# or: from zcore.security import Security

class Security:
    ...
```

---

## Password Hashing Methods (Argon2id)

ZCore configures `argon2-cffi` with dynamic hardware parameter tuning (`memory_cost`, `time_cost`, `parallelism`) from the active `Settings`.

### `hash_password`

Generates a secure Argon2id hash from a plain-text password.

```python
@staticmethod
def hash_password(password: str) -> str: ...
```

<TypeTable
  type={{
    password: {
      type: 'str',
      description: 'The plain-text password to hash.',
    },
    returns: {
      type: 'str',
      description: 'The computed Argon2id cryptographic hash string.',
    }
  }}
/>

### `verify_password`

Verifies a plain-text password against a stored Argon2id hash.

```python
@staticmethod
def verify_password(plain_password: str, hashed_password: str) -> bool: ...
```

<TypeTable
  type={{
    plain_password: {
      type: 'str',
      description: 'The unhashed candidate password.',
    },
    hashed_password: {
      type: 'str',
      description: 'The valid stored Argon2id hash string.',
    },
    returns: {
      type: 'bool',
      description: 'True if the candidate password matches the hash, False otherwise.',
    }
  }}
/>

## JWT Methods

### `create_jwt`

Creates a signed JWT access token.

```python
@classmethod
def create_jwt(
    cls, 
    data: dict, 
    expires_delta: Optional[timedelta] = None
) -> str: ...
```

<TypeTable
  type={{
    data: {
      type: 'dict',
      description: 'The payload claims dictionary to encode.',
    },
    expires_delta: {
      type: 'timedelta | None',
      default: 'None',

    },
    returns: {
      type: 'str',
      description: 'The signed JWT token string.',
    }
  }}
/>

### `decode_jwt`

Decodes, validates the signature, and checks the expiration of a signed JWT string.

```python
@classmethod

```

<TypeTable
  type={{
    token: {
      type: 'str',

    },
    returns: {
      type: 'dict',
      description: 'The decoded payload claims dictionary. Raises AuthError if expired or structurally invalid.',

  }}
/>

### `is_token_expired`

Checks if a Unix timestamp expiration claim has expired against UTC current time.

```python
@staticmethod
def is_token_expired(token_exp: int) -> bool: ...
```

<TypeTable
  type={{
    token_exp: {
      type: 'int',
      description: 'The Unix timestamp integer (the "exp" claim) to verify.',
    },
    returns: {
      type: 'bool',
      description: 'True if the timestamp is in the past or missing, False otherwise.',
    }
  }}
/>

<Callout type="warn" emoji="🚨">
  **Fail-Fast Production Secret Assertion:**
  The internal key resolver `_get_signing_keys()` actively asserts that if `settings.DEBUG` is `False` (Production) and `settings.SECRET_KEY` matches the default insecure fallback string, application startup is **aborted immediately** with a critical `RuntimeError`.
</Callout>
