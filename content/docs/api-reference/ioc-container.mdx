The `IoCContainer` manages class instantiation and lifecycles across your application. It handles registration, keyword-based constructor auto-wiring via cached reflection signatures, union type unwrapping, and circular dependency detection across **Singleton**, **Scoped**, and **Transient** lifecycles.

## Class Definition

```python
from zcore.kernel.di import IoCContainer

class IoCContainer:
    def __init__(self) -> None:
        ...
```

## Global Instance

ZCore exposes a pre-initialized global container instance used throughout the framework:

```python
from zcore import container
# or: from zcore.kernel.di import container
```

## Registration & Inspection Methods

### `is_registered`

Checks whether an interface or class is actively registered across any container lifecycle store (`_singletons`, `_scoped_definitions`, `_factories`), active request scopes (`_scoped_instances`), or represents `AsyncSession`. Automatically unwraps union and annotated types before verification.

```python
def is_registered(self, interface: type[Any]) -> bool: ...
```

    }
  }}
/>

### `_unwrap_type`

A static utility that recursively unwraps `Annotated`, `typing.Union`, and Python 3.10+ union types (`types.UnionType`, such as `IService | None = None`) to locate the underlying concrete dependency type.

```python
@staticmethod
def _unwrap_type(annotation: Any) -> Any: ...
```

Registers a pre-constructed instance as a shared global singleton.

## Resolution & Scope Management

### `resolve`

Dynamically evaluates registered bindings (Singleton, Scoped, Transient) or executes keyword-based constructor auto-wiring to assemble the dependency tree.

```python
def resolve(
    self, 
    interface: type[T], 
    _stack: set[type[Any]] | None = None
) -> T: ...
```

<TypeTable
  type={{
    interface: {
      type: 'type[T]',
      description: 'The interface or class type to resolve.',
    },
    returns: {
      type: 'T',
      description: 'The fully constructed and resolved instance of type T.',
    }
  }}
/>

<Callout type="warn" emoji="🛡️">
  **Scope Boundary Enforcement:**
  Attempting to resolve a scoped dependency or `AsyncSession` outside of an active scope context (when `_current_scope_id is None`) immediately raises `DIException`:
  ```text
  DIException: Cannot resolve scoped dependency 'TaskService' outside of an active scope.
  ```
</Callout>

<Callout type="info" emoji="⚡">
  **Constructor Auto-Wiring & `_DependencySignature` Caching:**
  When auto-wiring class constructors:
  * **Keyword Injection (`**kwargs`):** Dependencies are assembled into a keyword dictionary and injected via `target_class(**resolved_kwargs)`, preventing argument misplacement.
  * **Default Parameter Bypass:** Parameters declaring default values (`param.default is not empty`) that are not explicitly registered in the container (such as primitive `int`, `str`, or unregistered optional types) are skipped, allowing Python to safely apply their declared defaults.
  * **Signature Cache:** Evaluated parameter-to-dependency mappings are stored in `_dependency_signature_cache` as list-compatible `_DependencySignature` instances, bypassing reflection overhead on subsequent resolutions.
</Callout>

### `clear_scope`

Explicit scope cleanup hook called during middleware teardown to purge request-scoped instances.

```python
def clear_scope(self, scope_id: str | None = None) -> None: ...
```

## FastAPI Integration Helpers

### `Inject[T]`

Dynamic type marker bridging FastAPI route parameters with the IoC container via `Annotated`:

```python
from zcore import Inject

@router.get("/dashboard")
async def get_dashboard(service: Inject[DashboardService]):
    return await service.get_data()
```

### `Injector`

Callable wrapper class converting a type interface lookup into a FastAPI `Depends` resolver.

## Background Task & Scope Helpers

### `background_scope`

Asynchronous context manager providing an isolated IoC container scope, a dedicated `AsyncSession` database session, and `ZContext` variable storage for background execution independent of the originating HTTP request lifecycle.

```python
from zcore import background_scope

async def process_report():
    async with background_scope(inherit_context=True):
        ...
```

<TypeTable
  type={{
    inherit_context: {
      type: 'bool',
      default: 'True',
      description: 'Whether to clone active request context parameters (such as user_id and scopes) into the background scope.',
    },
    custom_context: {
      type: 'Any',
      description: 'Explicit key-value pairs to set or override in the background context store.',
    }
  }}
/>

### `background_task`

Decorator that wraps a background task with an isolated `background_scope` and automatically resolves any unprovided type-annotated parameters from the IoC container using `_unwrap_type`. Supports both asynchronous coroutines and synchronous functions (executed in a worker threadpool).

```python
import uuid
from zcore import background_task
from tasks.services import TaskService

@background_task
async def send_welcome_email(user_id: uuid.UUID, email_service: TaskService):
    await email_service.notify(user_id)
```

<Callout type="warn" emoji="⚠️">
  Passing an active request `AsyncSession` directly as an argument to background tasks is discouraged. Let `@background_task` automatically inject a dedicated, isolated session.
</Callout>

## Exceptions

### `CircularDependencyError`

Raised when a cyclic resolution loop is detected during dependency auto-wiring (e.g., `ServiceA -> ServiceB -> ServiceA`). Inherits from `DIException`.

### `DIException`

Base exception class for all container-level dependency injection runtime errors.
