The `Kernel` is the central core coordinator for the application lifespan and modular plugins. It assembles registered plugins into a Directed Acyclic Graph (DAG), resolves inter-plugin dependencies topologically, and orchestrates deterministic lifespan transitions.

## Class Definition

```python
from zcore import Kernel
# or: from zcore.kernel.engine import Kernel

class Kernel:
    def __init__(self) -> None:
        ...
```

### `setup`

Initializes plugin structures and registers core singletons in the IoC container. Sorts dependencies topologically, calls `plugin.setup(app)` on each plugin, and registers `EventDispatcher`.

```python
def setup(self, app: FastAPI) -> None: ...
```

<TypeTable
  type={{
    app: {
      type: 'FastAPI',
      description: 'The root FastAPI application instance.',
    }
  }}
/>

<Callout type="info" emoji="⚙️">
  **Dependency Resolution (`_resolve_dependencies`):** During `setup()`, the Kernel builds a dependency graph from declared plugin structures using `graphlib.TopologicalSorter`. It asserts graph integrity, raising a `RuntimeError` if a missing dependency is detected or if a cyclic dependency loop exists.
</Callout>

### `lifespan`

Asynchronous context manager governing the active FastAPI application lifespan. Sequentially invokes startup lifecycle phases on sorted plugins and guarantees clean, reversed teardown triggers upon termination.

```python
@asynccontextmanager
async def lifespan(self, app: FastAPI) -> AsyncGenerator[None, None]: ...
```

<TypeTable
  type={{
    app: {
      type: 'FastAPI',
      description: 'The active running FastAPI instance.',
    },
    returns: {
      type: 'AsyncGenerator[None, None]',
      description: 'An active async execution state context manager.',
    }
  }}
/>

<Callout type="warn" emoji="⚠️">
  **Lifespan Execution Order:**
  * **Startup (Topological Order):** `before_startup` $\rightarrow$ `on_startup` $\rightarrow$ `after_startup`.
  * **Shutdown (Reversed Topological Order):** `on_shutdown` is invoked in strictly reversed dependency order to ensure upstream resources remain available until dependents have closed cleanly.
</Callout>

## The `Plugin` Protocol

Any domain module intended to plug into the ZCore Kernel must implement the runtime-checkable `Plugin` protocol:

```python
from typing import Protocol, runtime_checkable
from fastapi import FastAPI

@runtime_checkable
class Plugin(Protocol):
    name: str
    version: str
    dependencies: list[str]

    def setup(self, app: FastAPI) -> None: ...
    async def before_startup(self) -> None: ...
    async def on_startup(self) -> None: ...
    async def after_startup(self) -> None: ...
    async def on_shutdown(self) -> None: ...
```
