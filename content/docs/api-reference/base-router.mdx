`BaseRouter` automatically scaffolds standard security-aware CRUD endpoints (POST, GET, GET_ALL, SEARCH, UPDATE, PATCH, DELETE) and coordinates services, validation schemas, and pagination handlers.

## Class Definition

```python
from zcore import BaseRouter, RouteKey

class BaseRouter(Generic[CreateSchemaType, UpdateSchemaType]):
    def __init__(self) -> None:
        ...
```

## Dependency Methods

### `get_route_action`

Retrieves the database/permission action name for a given route key using `model.actions()`.

```python
def get_route_action(self, route_key: RouteKey) -> str: ...
```

### `get_route_dependencies`

Generates default route dependencies (authentication, authorization, logging, etc.). Subclasses can override this method to inject dynamic, runtime dependencies per operation.

```python
def get_route_dependencies(self, route_key: RouteKey, action: str) -> list[Any]: ...
```

<TypeTable
  type={{

    },

<Callout type="info" emoji="💡">
  By default, `get_route_dependencies` returns `[HasScopes(action)]` to automatically enforce permission scopes mapped from `model.actions()`.
</Callout>

## Overridable Endpoint Handlers

Subclasses can override the core endpoint execution methods to customize response envelopes, inject custom query parameters, or set specialized HTTP status codes:

### `create_endpoint`
```python
async def create_endpoint(self, data_in: CreateSchemaType, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```

### `get_endpoint`
```python
async def get_endpoint(self, id: uuid.UUID, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```

### `get_all_endpoint`
```python
async def get_all_endpoint(self, service: BaseService, pagination: Any = None, **kwargs: Any) -> ResponseWrapper: ...
```

### `search_endpoint`
```python
async def search_endpoint(self, search_in: SearchRequest, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```

### `update_endpoint`
```python
async def update_endpoint(self, id: uuid.UUID, data_in: UpdateSchemaType, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```

### `patch_endpoint`
```python
async def patch_endpoint(self, id: uuid.UUID, data_in: UpdateSchemaType, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```

### `delete_endpoint`
```python
async def delete_endpoint(self, id: uuid.UUID, service: BaseService, **kwargs: Any) -> ResponseWrapper: ...
```
