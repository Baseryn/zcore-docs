`StreamManager` coordinates active listener queues and Redis PubSub operations. It facilitates cluster-wide event routing via subscription channels formatted as `stream:user:<uuid>`, falling back to local memory queues if Redis is unconfigured or offline.

## Methods

### `subscribe`

Subscribes a user, returning a bounded async listener queue. Initializes background Redis PubSub listeners if this is the first active subscription for a user on this node.

```python
async def subscribe(self, user_id: uuid.UUID) -> asyncio.Queue[Any]: ...
```

    returns: {
      type: 'asyncio.Queue[Any]',
      description: 'A bounded asyncio Queue (maxsize=100) configured to receive incoming event dictionaries.',

### `subscription`

Asynchronous context manager safely wrapping active user event streams. Guarantees automatic cleanup and queue unregistration upon block exit or connection drops.

```python

async def subscription(
    self, 
    user_id: uuid.UUID
) -> AsyncGenerator[asyncio.Queue[Any], None]: ...
```

## Usage Example (Server-Sent Events)

```python
import uuid
from fastapi import APIRouter
from fastapi.responses import StreamingResponse
from zcore.web import StreamManager

router = APIRouter()
stream_manager = StreamManager()

@router.get("/notifications/stream/{user_id}")
async def stream_notifications(user_id: uuid.UUID):
    async def event_generator():
        # Automatically registers and safely tears down queue on client disconnect
        async with stream_manager.subscription(user_id) as queue:
            while True:
                payload = await queue.get()
                yield f"data: {payload}\n\n"

    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

<Callout type="warn" emoji="🛡️">
  **Slow-Consumer Overflow Protection:**
  If a client consumes messages too slowly and their bounded queue reaches 100 items, `StreamManager` catches `asyncio.QueueFull`, immediately unregisters the stalled queue, and drops it to protect host node memory from buffer bloat.
</Callout>
