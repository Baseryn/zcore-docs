`BaseRepository` provides standard asynchronous database access, combining Read, Write, and Search capabilities. It decouples business logic from SQLAlchemy 2.0 sessions.

## Class Definition

```python
from zcore import BaseRepository

class BaseRepository(
    Generic[ModelType],
    ReadRepositoryMixin[ModelType],
    WriteRepositoryMixin[ModelType],
    SearchRepositoryMixin[ModelType]
):
    def __init__(self, model: Type[ModelType], db: AsyncSession):
        ...
```
