`BaseService` orchestrates domain logic, coordinates transaction boundaries via `_safe_commit()`, and exposes pre/on/post lifecycle interception hooks.

## Class Definition

```python
from zcore import BaseService

class BaseService(
    Generic[ModelType],
    ReadServiceMixin[ModelType],
    WriteServiceMixin[ModelType],
    SearchServiceMixin[ModelType]
):
    def __init__(self, model: Type[ModelType], repository: "BaseRepository"):
        ...
```

## Core Execution Methods (`on_*`)

These methods directly call the bound repository and can be overridden to customize persistence mechanics:

* `async def on_create(self, schema: BaseModel, **extra_data: Any) -> ModelType`
* `async def on_create_multi(self, schemas: List[BaseModel], refresh: bool = False) -> Sequence[ModelType]`
* `async def on_update(self, id: Any, schema: BaseModel, partial: bool = False, **extra_data: Any) -> Optional[ModelType]`
* `async def on_update_multi(self, data: Dict[Any, BaseModel], partial: bool = False, refresh: bool = False) -> Sequence[ModelType]`
* `async def on_delete(self, id: Any) -> Optional[ModelType]`
* `async def on_delete_multi(self, ids: List[Any]) -> Sequence[ModelType]`
* `async def on_search(self, search_in: SearchRequest, pagination: Any = None) -> Any`
